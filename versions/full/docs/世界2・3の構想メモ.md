# 世界2・3の構想メモ（10/31）

「決定」はチャットで決めたこと。「仮」はまだ数値や細部を決めていないこと。
作り方の約束: 世界2・3は世界1と同じ骨組みの上に、stages.js の欄で切り替えて作る。世界1の作りは変えない（世界1に直しが入れば世界2・3にも同じ直しが効く形）。

## 1. 世界ごとの違い（決定）

| | 世界1 原材料 | 世界2 製造工程 | 世界3 タオル進化 |
|---|---|---|---|
| 知識の性質 | 名前（これは何か） | 順番（どの順で作るか） | くらべる（どっちが／何が違う） |
| 発見の旅 | 双眼鏡で暗闇を探す | 箱を開けて探す | 無重力で探す（仮） |
| 救出の旅の敵 | 上から | 上から＋地上の敵 | 上から＋後ろから来る敵 |
| 問い（お題） | 3つから1つ「どれ？」 | 中ボス「次は？」、大ボス「3つを順に」 | 「どっち？」（仮） |
| 出来事 | なし | 6 コンベアが逆、7 照明が落ちる | 10 重力、11 流星雨 |
| 天気・時間帯の見た目（制作側の案） | 明け方〜夜、風、霧 | スポットライト、糸くずが転がる、蒸気の煙 | オーロラ、流れ星、星形の雲 |

4ステージのリズム（決定）: 各世界の1つ目は体験回（世界1のステージ1と同じ、初めての瞬間に1〜2行の案内）。4つ目はその世界の要素が全部混ざる。「総まとめ回（10秒の短い発見）」は作らない。

## 2. 世界2の発見の旅「箱」（決定）
- 工場の床（制作側の背景 world02_02）の上を、箱がコンベアで流れてくる。流れきる前に開けないと、しばらくして戻ってくる（時間切れなし、目安の秒数で加点・減点は世界1と同じ）
- 開ける操作: 箱を指で押さえ続けて1秒で開く（双眼鏡の「1秒見つめる」と同じ感覚）
- 開けると中からことばが出て、左の縦の札に入る。10個の箱に10のことば。空箱を少し混ぜる（仮: 2〜3個）
- 開けにくさの順: 5 大きい箱がゆっくり（体験）→ 6 「OPEN」の面が上を向いたときだけ開く（箱は回りながら流れる）→ 7 鍵つきの箱（先に鍵の箱を開ける）→ 8 全部が混ざる

## 3. 世界3の発見の旅「無重力」（仮）
- 星空（world03_02）で、ことばが回りながら漂う。候補の要素: 回転（向きがそろったときだけ見える）、くっつき（2つがくっついて1つに見える）、照らす（ふわりの光を当てると浮かぶ）
- 操作は世界1・2と同じ「合わせて1秒」にそろえる予定。細部は世界2を作ってから決める

## 4. 救出の旅の敵（決定）
- 世界2: 地上の敵が加わる（照準◎、たねを落とす仕組みは世界1の作りにある「世界2から」の分を使う）
- 世界3: 後ろ（画面の下）から来る敵が加わる
- 殻・虫・弾の見た目は世界ごと（仮。制作側の絵待ち）

## 5. 問い（決定）
- 世界2 中ボス「次は？」: 「○○の次は？」と1つ前の工程を示し、3つから次の工程を1つ選ぶ（操作は世界1と同じ）
- 世界2 大ボス「3つを順に」: 3つの工程のことばに、正しい順に光を当てる。当てたことばに 1・2・3 の番号がつく。順を間違えたら3つとも最初に戻る。間違えた瞬間に正しい順を一度だけ見せる
- 順番のデータは words.js の order の欄を使う
- 世界3「どっち？」: 2つのことばをくらべて選ぶ形（仮。細部は世界2のあと）

## 6. 必殺ワザ（決定）
- 4つ。レベルはなし。働きは1つずつ固定
  - ぜんぶ消し: 虫と弾をぜんぶ消す。殻には効かない（10/25-17の「殻を半分削る」はやめる。世界1の作りを変えるので、入れる時期はチャットで決める）
  - 時間止め: 4秒、敵も弾もことばも止まる（世界2ではコンベアも止まる見た目）
  - 無敵タイム: 10秒、ぶつかっても元気が減らない（タオルが周りを回る見た目）
  - 光のシャワー: 画面じゅうのことばの殻を半分削る
- 手に入る時期: ぜんぶ消し（最初から）、時間止め（ステージ5に初めて着いたとき）、無敵タイム（7）、光のシャワー（9）→ 正確な時期は 10.5 を見る
- 持ち物選択の画面に「必殺ワザ」の段を置き、持っているワザ（最大4つ）から1つ選んで出発。選んだワザが左下のボタンになる。世界1のあいだは1つしかないので選ぶ操作はない
- 新しいワザを手に入れた瞬間: 宝石ができた演出のあとに「新しい必殺ワザ『時間止め』を手に入れた！」の1画面
- 秒数と「半分」は仮。自動プレイヤーで測って動かす

## 7. 持ち物（決定）
- パワーUP／守りUP／必殺ワザ の3つは世界で変えない。「必殺ワザ」の持ち物は「選んだワザのゲージが満タンで始まる」の意味のまま
- 制作側の#21「単調」への答えは「必殺ワザを4つから選ぶ」

## 8. 出来事（決定・中身は仮）
- 世界1には入れない。世界2から
- ステージの途中で1回だけ起きる。6 コンベアが逆向きに流れる、7 照明が落ちて暗くなる、10 重力が変わる（ことばの落ち方が変わる）、11 流星雨（弾が増える）
- 起きる時刻と長さは仮。stages.js の欄で指定する作りにする

## 9. ワープの会話（決定）
- 会話は物語だけ。遊び方の変化は入れない（ステージ5・9の体験回の中で教える）
- 世界1→2（仮の文）
  ふわり「原材料の世界の記憶、4つの宝石になったね！ 綿のことは、だいぶ思い出した」
  ふわり「次は、糸からタオルができるまでの記憶。工場の世界に、ぼくの記憶が流れているみたい」
  主人公「工場だ！ 行こう！」
- 世界2→3（仮の文）

  ふわり「星の世界に、最後の宝石があるみたい。ここを終えれば、タオルのレシピがよみがえる！」

## 10.5 Claude Code向けの補足（読み違えやすいところ）
- 「世界1の作りは変えない」の意味: 共通の画面（持ち物選択など）に手を入れてよい。ただし、世界1を遊んだときに見えるものと数値は変えない。必殺ワザの段は、ワザが1つしかないあいだは今の見た目のまま
- ぜんぶ消しの「殻に効かない」は、今は変えない（世界1の作りのまま）。変える時期はチャットで決める
- 必殺ワザが手に入る時期は宝石の数で決める: 時間止め＝世界1の4つ目の宝石ができたとき（ワープの前）。無敵タイム＝世界2で2つ目の宝石ができたとき。光のシャワー＝世界2の4つ目の宝石ができたとき（ワープの前）。「手に入れた！」の1画面は、その宝石ができた演出の直後
- 世界2の発見の旅は、双眼鏡と暗闇を使わない。工場は明るく、箱が見えている。指で箱を直接押さえる
- 時間止めのあいだも、ふわりの光は出て、ことばの殻は削れる（止まっている的に当て放題）
- 地上の敵は、今のコードに残っている「世界2から」の分（照準◎、たねを落とす）を土台にする。帯の「地」の印を出すかは、ステージ5の計画で決める
- 世界2・3でも、救出の旅・お題（問いの形以外）・クイズ・カード・宝石・結果画面・レシピブックは世界1と同じ作りを使う。変えるのは、このメモに書いたところだけ
- 難易度の線（ステージ番号1〜12で一直線）は世界2・3でもそのまま続く。ステージ5の目安は線の値
- 「次は？」のお題に要る「1つ前の工程」のデータは、words.js の order の欄にあるものだけで足りるか確かめる。足りないことばは一覧にして判断待ち（データを足すのはチャットで決めてから）
- 天気・時間帯は、stages.js の theme と weather の欄に世界2・3の種類を足す形。世界1の種類は変えない
- 出来事の「6・7・10・11」はステージ番号
