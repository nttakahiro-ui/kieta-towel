# 消えたタオルと白い記憶 ― 11/5 の説明用まとめ

完全版（11/3）で遊べるところまでのまとめです。数字は、自動で遊ぶしくみ（ふつうの腕前の子ども）で1ステージ30回ずつ遊ばせた平均です。

## 1. ゲームの流れ

1つのステージは、次の順で進みます。12ステージで、タオルのレシピがよみがえります。

1. **オープニング**（最初の1回だけ）: タオルの「ふわり」の記憶が消えた、というお話。
2. **発見の旅**: 画面の中にかくれた10のことばを見つける。目安の秒数より早いほど点が高い。
3. **持ち物選択**: 「パワーUP／守りUP／必殺ワザ」から1つ選ぶ。必殺ワザが2つ以上あれば、使うワザも選ぶ。
4. **救出の旅**: 殻（から）にとらわれたことばに、ふわりの光を当てて助ける。虫や弾をよけながら進む。
5. **お題バトル**: 途中と最後に「お題」が出る。問いに合うことばに光を当てる（世界ごとに問いの形がちがう）。
6. **クイズ**: 助けたことば10こについて、1問ずつ答える。
7. **カード**: 正解したことばがカードになる（カード図鑑で読める）。
8. **宝石**: 10問すべて正解すると、そのステージの宝石ができる。
9. **12こでタオルのレシピ**: 3つの世界の宝石12こがそろうと、タオルのレシピが完成する。

## 2. 3つの世界の違い

| | 世界1　原材料（ステージ1〜4） | 世界2　製造工程（5〜8） | 世界3　タオル進化（9〜12） |
|---|---|---|---|
| 知識の性質 | 名前（これは何か） | 順番（どの順で作るか） | くらべる（どっちか、何がちがうか） |
| 発見の旅 | 暗い中を双眼鏡でさがし、1秒見つめる | コンベアを流れる箱を、指で押さえて開ける | 回りながらただようことばを、押さえてまっすぐにする |
| 救出の旅の敵 | 上から来る | 上から＋地上の敵 | 上から＋地上の敵＋うしろ（下）から |
| 問い（お題） | 3つから「どれ？」 | 「○○の次は？」、最後は「3つを順に」 | 2つから「どっち？」 |
| 必殺ワザ | ぜんぶ消し（4つ目の宝石で時間止め） | 4つから選ぶ（無敵タイム・光のシャワーが増える） | 4つから選ぶ |
| 出来事 | 風が逆になる、霧、うしろから虫、はさまれる | コンベアが逆、照明が落ちる、ねじが飛ぶ | 重力が変わる、流星雨、星がはじける |
| 背景の絵 | 森と畑（本番の絵） | 工場の床（本番の絵） | 星空（本番の絵） |

各世界の1つ目は「はじめての回」で、新しい遊び方を短い案内で教えます。4つ目は、その世界の要素が全部まざる山場です。

## 4. 3つのURLと、見るときの手順

| 名前 | URL | 中身 |
|---|---|---|
| 公開版 | https://nttakahiro-ui.github.io/kieta-towel/ | 世界1だけ（今みなさんに見てもらっている版） |
| 試作 | https://nttakahiro-ui.github.io/kieta-towel/versions/world23/ | 世界2・3を作ってきた途中の版（記録用。もう変えない） |
| **完全版** | https://nttakahiro-ui.github.io/kieta-towel/versions/full/ | 3つの世界、12ステージ全部。タイトルのいちばん下に「完全版 11/3」と出る |

**見るときの手順**

1. iPhone の **Safari** で開いてください（ほかのアプリの中のブラウザでは、音や全画面がうまく動かないことがあります）。
2. 音は、最初に画面をタップしたときから出ます（「始める」を押すと鳴ります）。消すときは、タイトルの「音: オン」を押します。
3. 世界2・3からすぐ見たいときは、URLの終わりに **?debug** をつけて開きます（例: …/versions/full/?debug）。世界1の宝石4つ・カード40枚を持った状態から始まり、「世界2へワープ」ですぐ世界2へ行けます。
4. 遊んだ記録はブラウザに残ります。最初からやり直すときは、タイトルの「記録を消す」を押します。
