  - 並べ替え問題10問は、順序そのものを選ぶ3択に書きかえた（問題文も「正しい順番はどれ?」の形に）

  - タイトル → バトル → クイズ10問 → カード表示 → （10枚そろえば）レシピ完成
  - バトルの調整用の数値は `js/game.js` の先頭 `BATTLE`、敵の弾の絵は `ENEMY_BULLET_ART` にまとめた
  - 曲の指定は `js/audio.js` の先頭 `SONGS`。`file` に曲ファイルのパスを入れると差し替わる
  - パソコンのブラウザ（スマホの大きさ）で通しの動作を確認。画面なしの早回しで、やられたあとの再開と、大ボスが最後に出ることも確認
  - 早回しの目安: 敵をすべて撃ち落とせる人で約70秒、取りこぼしが多いと約2分〜4分

- 作り込み（V01の範囲内）
  - ふわりの段階: 集めたカードの総数で色と弾の数が変わる（0〜9枚: 1発、10枚〜: 2発、20枚〜: 3発、30枚〜: 3発で連射が速い）。表は `js/game.js` の `FUWARI_LEVELS`
  - 吸い込むときにふわりが光る。被弾すると画面がゆれて、ふちがうすく赤くなる。体力が少ないと体力の帯が点滅
  - 大ボスの登場に「大ボス あらわる！」の帯と音。降りてくる間はうすく表示され、弾が当たらない
  - 最初は「ゆびでドラッグしてうごかそう」のヒントを表示（一度動かすと消える）
  - アプリを裏に回すと、バトルと音が止まる。戻ってタップするとつづきから
  - クイズで正解すると「カードゲット！」が出る。カード画面で、はじめて集めたカードに NEW の印
  - レシピ完成の画面に綿毛が舞う（仮の演出）
  - タイトルに「記録を消す」（試すとき用。確認つき）
- 調整パネル: 公開URLの最後に `?tune` をつけて開くと（https://nttakahiro-ui.github.io/kieta-towel/?tune ）、タイトルに「調整パネル」が出る
  - 敵の間隔・速さ・弾・体力・硬さ・語句の表示時間など15項目をスライダーで変えられる。その端末にだけ保存。変えているとタイトルに「調整中」の印
  - 「数値をコピー」で、変えた項目だけが文字になる。チャットに貼れば、その数値を `js/game.js` の初期値に入れる
- バトルの記録（時間・被弾・やられた回数）を、クリア時とカード画面に表示
- 中ボスは2方向に弾を撃つ。敵の弾の向きは `BATTLE.shotPattern` で変えられる
- ふわりのセリフを `js/quiz.js` の `FUWARI_SAY` にまとめ、毎回ちがうものが出るようにした（3問れんぞく正解・最後の問題でも話す）
  - `data/words.js` の sayCorrect / sayWrong は空にした。書けばその語句だけのセリフになる

## 困ったこと・判断待ち

- **ステージ1の大ボス**: v53 の boss 欄は「綿花」だが、ステージ1の10語に「綿花」がない。仮に「コットンボール」を大ボスにした（一言メモが「綿花とはこのコットンボールのこと」のため）。同じく、ステージ7は「ジャカード」→「ジャカード織機」、ステージ12は「柔軟剤」→「柔軟剤の使いすぎ」に仮置き
- **中ボス**: 各ステージ2語を機械的に仮置き（ステージ1は「リント」「綿の花」）。本人が決める
- **ステージ2〜12の名前**: 9/14資料の表をまだ受け取っていないので、v53 のテーマ名に「（仮）」をつけて入れた。表をもらえれば `data/stages.js` に入れる
- **7割クリアの数え方**: 今は「そのステージで今までに集めたカードの合計が7枚以上」でクリア。1回のクイズで7問正解が必要、という意味なら直す
- **ふわりの段階の中身**: 決定事項メモの「10枚ごとに弾が増えるなど3〜4段階」から、上の4段階を仮に決めた。10枚集めたあとステージ1を遊び直すと弾が2発になり、やさしくなる
- **ふわりのセリフ**: `FUWARI_SAY` の文面はすべて仮。9/14資料の調子に合わせて差し替えてほしい
