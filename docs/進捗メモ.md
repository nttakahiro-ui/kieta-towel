## 今日やったこと（10/2〜10/3）

- **GitHubの準備**: 公開リポジトリ `kieta-towel` を作成し、GitHub Pages（main ブランチ直下）を有効化
  - 公開方法は「公開リポジトリ＋検索に出ない設定」。`資料/` は .gitignore でリポジトリから除外
  - commit の作者メールは GitHub の非公開用アドレス（nttakahiro-ui@users.noreply.github.com）
- **データ**: v53 の THEMES から120語を `data/words.js` に（12ステージ×10語）。3世界・12ステージを `data/stages.js` に
  - 読み仮名は macOS の読み変換で自動で入れ、おかしいものは手で直した
  - 並べ替え問題10問は、順序そのものを選ぶ3択に書きかえた
  - 役割は各ステージ「大ボス1・中ボス2・ザコ7」、硬さはザコ1・中ボス3・大ボス6
- **バトル**（`js/game.js`。調整用の数値は先頭の `BATTLE` にまとめた）
  - 指一本のドラッグ、自動連射。語句を倒すと糸のようにほどけて吸い込み、画面中央に読み仮名つきで0.6秒表示
  - 空中と地上の2層（10/3 チャットで決定）: 地面（綿畑・草地・小川・あぜ道）が流れ、影で奥行きを出した
    - 空中の雑魚: てんとう虫・ハチ・綿毛おばけ。地上の雑魚: からまり草・いばらの株
    - 地上の敵は、自機の前の照準◎に入ると自動で「たね」を落として倒す。10語のうち3語（ザコから）は地上に出る
    - 雑魚は倒すと花になり、30%で金色の「綿のたね」（体力回復）を落とす
    - 雑魚の種類と出やすさは `FILLER_TYPES` / `FILLER_WAVES`
  - 大ボスは最後に「大ボス あらわる！」で登場。体力ゼロでも吸い込んだ語句は残して再開
  - ふわりの段階（集めたカードの数で色と弾の数が変わる）: `FUWARI_LEVELS`
  - 被弾のゆれ、操作のヒント、アプリを裏に回したときの一時停止、バトルの記録（時間・被弾回数）
- **クイズ・カード**（`js/quiz.js`、`js/cards.js`）
  - 吸い込んだ順に10問。選択肢は毎回入れ替え。不正解は正解と一言メモを表示。3問目と8問目でテンポアップ
  - 正解で「カードゲット！」、カード画面で NEW の印。10枚でレシピ完成「綿花のひみつ」、7枚でステージクリア
  - ふわりのセリフは `FUWARI_SAY` にまとめた（語句ごとのセリフは words.js の sayCorrect / sayWrong に書ける）
- **音**（`js/audio.js`）: 仮の曲（タイトル・バトル・クイズ・カード・レシピ）と効果音。曲の差し替えは先頭の `SONGS`
- **試す人向け**: タイトルの「記録を消す」。URLに `?tune` で調整パネル（23項目。「数値をコピー」でチャットに貼れる）
- **確認**: パソコンのブラウザ（スマホの大きさ）で通しの動作を確認。画面なしの早回しで、最後まで進むこと・大ボスが最後に出ること・やられたあとの再開を確認
  - 早回しの目安: 動き回る人で約80〜140秒、ほとんど動かない人で約2〜3分
  - iPhone の実機ではまだ試していない
