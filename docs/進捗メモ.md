## 判断待ち（世界2・3）

構想メモに書いていないところは「世界1と同じ」か「いちばん単純な形」を選んだ。番号つきで、選んだものと理由。

1. 帯の「地」の印は出さない（指示の既定）。地面のことばは影を濃くするだけ（世界1の絵の地面の盛り土と木のかげは使わない）
2. 「次は？」の1つ前の工程のデータ（words.js の order が1つ前のことば）が足りるかを確かめた。足りるのは2つだけで、ほかは「どれ？」のまま（データを足すのはチャットで決めてから）
   - ステージ5 撚糸: order 2 は糊付け。本当の工程は「撚糸 → 糊付け」の順なので、order の並びが工程の順と合わない →「どれ？」
   - ステージ5 検査: order 6 は縫製。「縫製の次は？」→ 検査（工程の順と合う）→「次は？」にした
   - ステージ6 混打綿: order 3 がない（2 は練条）。混打綿は糸づくりの最初の工程で、1つ前がない →「どれ？」
   - ステージ6 スライバー: order 7 はリング精紡機。スライバーは工程ではなく繊維の状態の名前 →「どれ？」
   - ステージ7 パイル経糸: order 2 はパイル。どちらも工程の名前ではない →「どれ？」
   - ステージ7 ドビー織機: order 7 がない（6 は3種の糸）。織機の名前 →「どれ？」
   - ステージ8 漂白: order 2 は精練。「精練の次は？」→ 漂白（晒し＝精練＋漂白の順と合う）→「次は？」にした
   - ステージ8 ヘム: order 7 は脱毛率。工程ではない →「どれ？」
   - 「次は？」の3つの選ぶことばは、世界1と同じ決め方（同じステージの、文字数が近いことば2つ。1つ前の工程そのものは入れない）。ステージ5の検査は「検査・紡績・撚糸」になる
   - 「次は？」にする中ボスは stages.js の nextAsk 欄に書く形にした（order から機械的に決めると、上の撚糸のように工程の順とちがう問いになるため）
3. 箱の発見の旅の数（仮。自動プレイヤーで測った）: 箱の大きさ 88×64px、流れる速さ 32px/秒、箱が出てくる間隔 2.6秒、流れきってから戻るまで 2秒、空箱 2個、押さえる時間 1秒。コンベアは横向き3本（画面の高さの30%・52%・74%）、左から右へ流れる
4. 箱の発見の旅の背景（world02_02）は流さずに止めておく（工場の床の上を、コンベアだけが動く見た目にするため）。コンベアと箱は仮の図形
5. 押さえるのをやめると、たまった輪は0にもどる（「押さえ続けて1秒」のとおり）
6. 新しい必殺ワザを手に入れたら、そのワザを選んだ状態にする（持ち物選択の画面の段で選びなおせる。選んだワザは次のステージでも続く）
7. 持ち物選択の「必殺ワザ」の段は、3つのボタンの下に小さく1列（ワザが4つのときは2列）。右下の一時停止のボタンと重ならない幅。ワザが1つのあいだは段を出さない
8. 時間止めのあいだは、地面のスクロール、ことばの出てくる台本、中ボスのお題の制限時間も止まる。止まっている弾にはぶつからない（はじめは「ぶつかる」で作ったが、自動プレイヤーで時間止めを使うと被弾がふえたので、助けになるほうにした）
9. 世界2の救出の旅の背景は bg_world2.jpg（工場）。世界1の綿の実などの飾りは流さない。虫・殻・弾は世界1の絵の色を変えただけ（虫は CSS の色相を180度回す）。地面の虫は世界1の「からまり草」「いばらの株」の形のまま。木（障害物）は出さない

18. 出来事は、どれも発見の旅のあいだに起きる（6 コンベアが逆: 14秒から8秒、7 照明が落ちる: 12秒から6秒、8 は両方: 逆 10秒から6秒・照明 24秒から5秒）。起きた瞬間に帯で1回知らせる。「照明が落ちる」は画面ぜんたいに暗い色をかぶせるだけ（箱とかぎの印はうすく見える）

20. 「3つを順に」にする大ボスは stages.js の bossOrder: true で、大ボスの choices の1つ目が「A→B→C」の3つで、その中に大ボスのことばがあるときだけ。ステージ6 精紡（練条→粗紡→精紡）だけが当てはまる。ステージ7 ジャカード織機・ステージ8 検針機は choices が2つのことばなので「どれ？」のまま（データを足すのはチャットで決めてから）
