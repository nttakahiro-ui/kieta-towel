## 目的と体制

タオルソムリエのゲームをもとに、小学4年生〜中学生向けのスマホのブラウザゲームのテスト版（プロトタイプ）を、Claude Code で作る。本格版はプロが作る。このテスト版は、最終案まで作り続ける土台。

- 仮タイトル: 消えたタオルと白い記憶 〜消えたレシピを探す旅〜〔10/2〕
- ターゲット: 小学4年生から中学生が中心。大人も楽しめる入門ゲーム〔10/2〕
- 作る期間と時間: 1か月、1日60分ほど（遊ぶ時間の目安とは別）〔10/2・10/25-22〕
- 元資料: 9/7 関係者共有まとめ、9/14 確認事項、タオルの学校_入門編_v53_カード一覧.xlsx、タオルの学校_入門編_v53.html。食い違うところは9/14を優先〔10/2〕
- 役割分担: 本人の試作はバトルとクイズ。世界観、キャラ、本格版の音楽、背景、絵は制作担当者（デザインチーム）が作る〔10/2〕
- 入門編（v53）のコードは使わず、新しく作る。v53から使うのはカードとクイズの知識データだけ。学校の呼び方（1年生・卒業など）は使わず、世界名（原材料の世界・製造工程の世界・タオル進化の世界）にする〔10/2〕
- 直しやすさ（どこを触れば何が変わるか）をゲーム性と同じ重さで扱う。仮で済ませていたところは、順に本物の作りに置き換える〔10/21-1〕
- 直す場所は3つ: ことばのデータ（data/words.js）、ステージの数値（data/stages.js）、画面の言葉（data/texts.js）〔10/21-1〕
- 進め方: 世界1の最初のステージを通して遊べる形にしてから広げる。公開は GitHub Pages、スマホはURLで開いて試す。ゲーム（バトル）が先、シナリオはあと。細かい調整は触って決める〔10/2〕

### 運用

- チャットは「決める場所」、Claude Code は「作る場所」。「決定:」で始まる指示は、この文書の該当する項目を書き換え（出どころの番号を更新）、docs/変更の記録.md のいちばん下に日付つきで足す〔10/2・10/25-22・10/25-25〕
- Claude Code は、作業の終わりに進捗メモ（今日やったこと、次にやること、判断待ち）を更新する〔10/2〕
- 大きく変える前は、先に計画を見せてから作る。作業中に判断が必要になったら、Claude Code で決めず、進捗メモの判断待ちに書いてチャットに持ち帰る〔10/2〕
- 1日60分の型: 最初の5分で進捗メモを読む、中の45分で作って確かめる、最後の10分で動く状態にして保存する〔10/2〕

## データ

- 120のことば（世界ごとに40、ステージごとに10）は、data/words.js に1か所でまとめる。今はv53の120語〔10/2〕
- ことばごとの欄: id、ステージ、ことば、読み、問題、選択肢（2つか3つ）、正解の番号、一言メモ、役割（ザコ／中ボス／大ボス）、硬さ、正解・不正解のときのふわりのセリフ、出る順番、出方、出る位置、文字ごとの読み（中ボス・大ボス）、お題の問い〔10/2・10/3・10/5・作り〕
- 問題・選択肢・正解・一言メモ・お題の問い・ふわりのセリフは、words.js の欄だけに持つ。game.js や quiz.js に問題の文章を書かない。words.js の1行を直せば、お題もクイズもカードも同時に変わる〔10/3-13〕
- お題の問い（odaiQuestion）は、答えがそのことば自身になる形（「〜は？」）。空なら問題（question）を使う。ふつうのクイズの問題文は変えない〔10/5・10/3-13〕
- 並べかえの問題（製造工程の世界に多い）は、順序そのものを選択肢にして3択にする（例: ABC／ACB／BAC）〔10/2〕
- 大ボスはv53の各ステージの「boss」から。中ボスは仮置きで、最後に本人が決める。入れかえは役割の欄を書きかえるだけ〔10/2〕
- ステージ1は、大ボス「天然の撚り」、中ボス「コットンボール」「繊維長」〔10/3・10/25-17〕
- 出方の型: ふつう、端にかくれる、横切る、虫のうしろ（雑魚のうしろ）、木のかげ、地上（世界2から）〔10/3・10/8・作り〕
- ステージ1は、出方を words.js の欄で決める（ルーメン＝端にかくれる、リント・植物繊維＝横切る、リンター＝虫のうしろ）。ステージ2からは、意地の悪いことばの数（難易度の線）から自動で決める（毎回同じ並びになる）〔10/3・作り〕
- words.js の先頭に、欄の意味と直し方の説明がある。120語は docs/words.csv にも書き出し、表計算で直せる。行き来は tools/words_csv.js（export／import）〔10/3-13〕
- ことばに関係しないふわりの決まり文句（クイズの「そうだ！思い出した！」など）は js/quiz.js の FUWARI_SAY〔10/3-14〕
- stages.js の欄: ステージ名、トピック、レシピ名、宝石の色、遊べるか、難易度、出方の決め方、発見の動きの型、木、天気、時間帯の色と背景の絵と虫、ステージごとの数値の上書き、チュートリアルの印〔作り〕
- texts.js: 画面の言葉をすべてここに置く。世界ごとにちがう言葉（種の名前など）は世界ごとに持つ〔10/21-1〕

## 救出の旅

ことばは殻にとらわれて、上から降りてくる。ふわりの光を当てて殻をほどき、ことばを助ける。殻を守る虫が弾を撃ってくるので、指でふわりを動かしてよける。

### 基本の流れ

- 発見の旅のあとの2つ目の旅。10のことばが、ステージごとに決まった順番と出方で降りてくる（ランダムにしない）〔10/3・10/3-11〕
- 10のことばの内訳は、ザコ6〜7、中ボス2〜3、大ボス1（最後）。中ボスと大ボスはお題で出る（お題バトルの節）〔10/2・10/5〕
- ザコのことばを出し終え、画面からいなくなったら大ボスのお題〔作り〕
- 画面の下まで抜けたことばは取り逃がし。大ボスのあとの延長戦か、結果画面の「救出の旅をもう一度」で助けられる〔10/25-14・10/25-19〕
- 助けた瞬間: 0.3秒ほど画面がゆっくりになり（速さ0.25倍）、ことばとふりがなを中央に1.5秒大きく出して読み上げる。その間は弾が当たらない〔10/3・10/4〕
- 【未実装】ことばの読み上げはやめる。コードは残し、調整パネルに「読み上げ: オン／オフ」を置いて初期値はオフ（指摘35）〔10/31-3〕
- 助けた瞬間に光が広がり、虫と敵の弾が消える（コガネムシとその弾は残る）〔10/3・10/25-2〕
- 左端の「10のあき枠」: 見つけていないことばは「？」、発見の旅で見つけたことばは灰色、助けたことばは金色〔10/8・10/3-2〕
- 上の表示は、元気のゲージ・元気3つ・点数だけ〔10/3-2・10/3-3〕
- 得点: 助けたことば1000点、虫100点。続けて助けるとコンボ（1→1.5→2…、最大3倍）〔10/3・作り〕
- ステージ1だけ: 1語目（アオイ科）が画面の高さの42%で止まって待ち、助けるまで弾も虫も出さない。ことばの出る間隔は11秒（ほかは4.2秒）。お題で殻から弾を撃たない（ステージ2から撃つ）〔10/25-1・作り〕

### ことばと殻

- 殻は役割で分ける: ザコ＝綿毛のまゆ、中ボス＝いばら、大ボス＝霧〔10/3-11〕
- ザコの殻の硬さ（光1本あたり）は、ステージ1で9、ステージ12で8（間は線で結ぶ）。ふわりの光1発で0.35削る〔作り〕
- 光の本数（太い光は2本分）で割って削るので、パワーが上がっても、全部当たればほどけるまでの時間は同じ〔10/3-8〕
- 基準: 光を当て続けて、ことばが画面の高さの30〜50%に来るころにほどける。自動プレイヤーのふつうで、ステージ1 33%、2 33%、3 40%、4 41%〔10/25-11・作り〕
- 出方ごとの殻の硬さ: 横切ることばは0.5倍、端にかくれることばは0.3倍、木のかげのことばは1.4倍（調整値も見る）〔10/25-22・作り〕
- 横切ることばは、画面の高さの47%のあたりを6秒で横切る〔10/25-9・作り〕
- 端にかくれることばは、右端で出たり引っこんだりしながら13.5秒で降りる。全部出ているときだけ光が当たる〔10/3・作り〕
- 中ボス・大ボスは、文字ごとに殻があり、1文字ずつほどける。ほどけるたびにその文字の読みが鳴る。全部ほどけると助けられる〔10/3〕
- 中ボス・大ボスの硬さ: 全体の硬さ（中ボス12、大ボス60）を文字数で割り、1文字あたり中ボス2〜6、大ボス6〜30におさめ、ステージの倍率（ステージ1で1.1、ステージ12で2）をかける。光1発で1削る〔10/4・作り〕
- かっこと、かっこの中の別名は、ほどく文字と読み上げから外す〔10/4〕
- 1〜2文字のことばは、横切る・端にかくれるにしない。文字を1.3倍で出す〔10/4・作り〕
- 文字の大きさはザコ26px、中ボス30px、大ボス36px。漢字の上にふりがな（13px）と光る縁取り〔10/3・作り〕
- ことばは画面に全部入るまで光が当たらない。入ってから1秒は止まって光る（「来た」とわかる）〔10/8・10/3-4〕
- 当たり判定は、文字の幅の左右にさらに28px〔10/3-10〕
- 殻の残りが2割以下になると黄色く光る（あと少しの印）。中ボス・大ボスは文字ごと〔10/25-16〕
- 大ボスの殻が2割減るごとに、ふわりの短い声（「いいぞ！」「その調子！」「あと少し！」「もうひといき！」）〔10/25-17〕

## 画面の言葉

- 方針: ゲームの定番語（パワーUP、必殺ワザ、ノーダメージ、ステージクリア、レベルなど）は使う。軍の言葉（出撃、残機、偵察、撃墜など）は使わない。小4までに習う漢字は漢字、それ以外はふりがなか言い換え〔10/25-22〕
- 画面の呼び名: 発見の旅、救出の旅、ことば、殻、ふわりの光、元気（元気のゲージ・元気3つ）、ぜんぶ消し、助ける、森の種〔10/3-11・10/3-12・10/25-5〕
- 「出撃」「残機」「大ボス」「中ボス」「雑魚」は画面に出さない（コードと調整パネルの中はそのまま）〔10/3-11〕
- 作り手の言葉（帯、HUD など）は案内に使わない〔10/21-1〕
- 数えるときは「語」でなく「ことば」（「10のことば」「あと3つのことば」）。「名前」も「ことば」（人や世界の名前は除く）〔10/25-13・10/25-20〕
- 1画面に1つの要点。同じことを2か所に書かない〔10/25-1〕
- 小4で習わない漢字は言い換える（倒す→やっつける、回復→元気がもどる、戻る→もどる）。固有名詞と決まった言葉はふりがな〔10/25-6〕
- ふりがな: 見出し（旅の名前、持ち物の名前）は texts.js の kana 欄で、字の上に小さく。ふつうの文は、遊ぶ人が初めて目にする文にだけ「殻（から）」のようにカッコで添える（今は 双眼鏡＝発見の旅の指の案内、殻＝救出の旅の前のふわりの一言、正解＝クイズの前の1画面、必殺＝持ち物の名前のふりがな）〔10/25-6・10/25-17〕
- 案内は点滅させず、出るときに一度ふわっと現れるだけ。「タップで出発！」「タップで次へ」などの押せる印は、ゆっくり点滅〔10/25-12・10/25-13〕
- 画面の言葉はすべて data/texts.js〔10/21-1〕

## 見た目と音

- 方向はメルヘン。軍用機・爆発・金属の雰囲気は使わない。丸みのある形、やわらかい色。殻は「ほどける」（糸がほどけるように散る）、音もふわっとしたもの〔10/2〕
- フォントは丸ゴシック（iPhone はヒラギノ丸ゴ、ほかは Zen Maru Gothic）。指定は css/style.css の1か所〔10/3-5〕
- 世界1の時間帯: ステージ1 明け方、2 真昼、3 夕暮れ、4 夜。背景は森の絵（assets/bg_world1.jpg）に時間帯の色を薄くかける。色・絵・虫・ことばの縁取りの色は stages.js の theme 欄〔10/3-5・10/3-6・10/21-1〕
- 夕暮れは、ことばの縁取りを濃い茶色にして、だいだい色の地面と見分ける。夜の森は木の影を濃く〔10/3-5・10/3-6〕
- 背景の絵は固定し、地面の飾りだけを背景の上でゆっくり流す。木・虫・ことばは絵の上〔10/21-1・10/22-1〕
- 主人公の絵（男の子・女の子 × 指さす・考える・喜ぶ）は切り抜かず、画面の色に溶けこむ描き方〔10/21-1〕
- ふわりの絵は3コマ（assets/fuwari_1〜3.png。資料/絵/ の絵を tools/fuwari_cut.js で切り出したもの）。使う場所: 自機（1→2→3）、発見の旅の下のまん中（1）、助けた瞬間（2）、ぜんぶ消し（3を大きく）、吹き出しの横（1）、目的の画面（1）、持ち物選択（2）、元気3つ（1）、ぜんぶ消しのボタン（1、たまったら3）、レシピ完成とワープ（3）〔10/25-6・10/25-12・10/25-14〕
- 自機はふわりだけ（A君はふわりに乗っている設定。主人公をふわりの横に置かない）〔10/25-12〕
- 雑魚（虫）の絵とふわりのセリフは仮。制作担当者が決める〔10/3〕
- 【未実装】本番の絵（資料/絵/制作者側_1030/）の組み込みは、今ある画面の差し替えを先にやる。順番は タイトル → ステージ選択 → 発見の旅 → 一時停止 → 持ち物選択 → カード図鑑。オープニング（11枚）はその後〔10/31-2〕
- 絵に焼き込まれている文字（図鑑の見出しの「レシピ：〜」、見本の「レシピ 1/12」など）は、制作側に作り直しを頼まず、ゲーム側で扱う。文字の部分を切る・隠す・上から描く、のどれにするかは絵ごとに決めて、その画面の計画に書く〔10/31-2〕
- 音のオン・オフ: タイトルと一時停止メニューにボタン（「音: オン」「音: オフ」）。ブラウザに保存〔10/21-1〕
