## お題の形
- 「次は？」（世界2の中ボス）: 「○○の次は？」と1つ前の工程（stages.js の nextAsk）を出し、2つから選ぶ（10/31-13 決定。見出しは「2つから選ぼう！」）。もう1つは工程の順で1つあとのことば（nextAsk の after。5 撚糸→糊付け、検査→（なし）、6 梳綿→練条・粗紡→精紡、8 漂白→乾燥・乾燥→耳巻き）。ないときは、長さのいちばん近いことば
- 「3つを順に」（世界2の大ボス）: 3つのことば（stages.js の bossOrder）に正しい順に光を当てる。問題文はステージごと（5「タオルの生地ができる順に、光を当てよう！」、6「糸ができる順に、光を当てよう！」、8「タオルが仕上がる順に、光を当てよう！」）。同じことばに続けて3発で「当てた」。番号 1・2・3 がつく。まちがえたら最初にもどって、正しい順を1.8秒見せる
- 「どっち？」（世界3の中ボス・大ボス）: 2つのことばを左右の2列に出す。問題文の「は？」を「はどっち？」にする。もう1つのことばは choices の2つ目（同じステージにあることばなら、それを使う）
- データがないときは、どれも世界1と同じ「どれ？」

### お題バトルのあいだ（11/1 決定。全世界）
- お題のことばの文字は前の0.8倍（odaiTextScale）。読む時間は前のまま
- 3つのことばは画面の幅の15%・50%・85%、2つ（どっち？・次は？の2択）は20%・80%（odaiColumns・odaiColumns2）
- 殻は同時でなく、順番に1つずつ撃つ。弾の総数は前と同じ（前の間隔を殻の数で割った間隔で、順に回す）
- 弾の形（stages.js の odaiShot）: 扇（今の3方向）／ねらい（ふわりに向けて1発ずつ、0.18秒おき）／横ながし（左から右へ7列を順に、まっすぐ落ちる）／輪（撃つ数をためて6発の輪）／ななめ雨（問題文のすぐ下から、ななめに。向きは交互）。数は BATTLE.odaiShots
- 弾の間隔: 形ごとに1.4倍（odaiShots.gap）と、ステージごとの odaiGap。秒数が長くなったぶん、被弾が前の2割増しまでになるようにした
- パワー（光の本数）はお題のあいだも保つ（前は正面1本だけ）。光の広がりは0.35倍で正面寄り（odaiSpread）
- 「同じことばに0.35秒以内に3発当てたときだけ当てたと数える」を、「どれ？」「次は？」「どっち？」にも使う（横切った光ではまちがいにならない）

## クイズ（救出のあとのクイズ）

- 世界1（1〜4）は今のまま（2〜3択）

## 必殺ワザを駆使する回（11/1-3 決定。全世界）
- 各世界の3つ目（3・7・11）と4つ目（4・8・12）は、救出の旅を長く・虫を多く・出来事を多くして、必殺ワザを何回も使う回にした（stages.js の rescueLen・bugMul・gaugeRate）
- 長くするのは、ことばの出る間隔を広げる形（10語は変えない）。木・柱の出る時刻も同じ倍率でずらす（ずらさないと、柱のかげのことばの時刻と合わなくなる）。中ボス・大ボスの硬さ、発見の旅は変えない
- ゲージが速くたまるのは救出の旅（中ボス・大ボスのお題のあいだもふくむ）。発見の旅で見つけたときのたまり方は変えない
- 新しい出来事（js/game.js の evStart。起きた瞬間に帯で1回知らせる。同じ出来事が2回あれば2回とも知らせる）
  - うしろから虫の群れ（rear）: 下のはしに1.5秒「！」、そのあと画面の下から綿毛おばけ4匹（BATTLE.rearSwarm）
  - はさまれる（pinch）: 障害物2つが左右から同時に。あいだの道は画面の幅の3割（BATTLE.pinchGap）、道の位置は毎回 35〜65% のどこか。ふれると被弾。光と弾はさえぎらない（さえぎると端のことばが助けられなくなるため）
  - 風（wind）・風が逆（windRev）: 世界1 の天気の風と同じ作り（ふわりと夕暮れの虫が流される）。風が逆のあいだは向きが逆
  - 霧（fog）: 霧がこくなる。ふだんの霧（上から BATTLE.fogTop まで）が、上から45%まで下りてくる（BATTLE.fogTopEvent）
- 時刻（救出の旅の時計。お題のあいだは止まる）は進捗メモの第10段階

## 必殺ワザ
- 4つ: ぜんぶ消し（最初から）、時間止め（世界1の4つ目の宝石）、無敵タイム（世界2の2つ目の宝石）、光のシャワー（世界2の4つ目の宝石）。手に入れたら、宝石の画面のあとに「新しい必殺ワザ『○○』を手に入れた！」の1画面（index.html の screen-skill）
- 持ち物選択の画面に「必殺ワザ」の段（ワザが1つのあいだは出さない）。選んだワザが左下のボタンになる。ゲージと持ち物「必殺ワザ」は世界1と同じ
- 時間止め 4秒（敵・弾・ことば・虫・台本が止まる。止まっている弾にはぶつからない）、無敵タイム 10秒（タオルが周りを回る）、光のシャワー（画面のことばの殻を半分削る）

## 自動プレイヤーに足したこと
- 箱・無重力: いちばん近い箱（ことば）へ指を動かして押さえる。無重力では、光っている（60度の中の）ことばを先に（10/31-14）。鍵の箱に一度はじかれたら、鍵が見つかるまでさわらない
- 地上のことば: 空中と同じく、真上（左右）に合わせるだけ（10/31-12。前は◎を合わせるように上下にも動いた）。隠れているときは、ほかに見えていることばがあればそちらを先に、なければ下で顔を出すのを待つ。動くことばにはついていく（10/31-13）
- 「3つを順に」: 順を知っている確率で正しいことばをねらう。まちがえて正しい順を見たあとは正しい順に
- SKILL=stop などで、そのワザを持って遊ぶ
- SLOWLOG=1 で、救出の旅と大ボスのあいだの「わざとのスロー」（助けた瞬間・初めての案内・お題を読む・順のまちがい・帯）の回数と、ゆっくりの合計秒数を出す（10/31-14）
- 「お題 ふつう: 中ボスのお題 ○秒（N回） お題のあいだの被弾 ○」の行（11/1）。お題のあいだの被弾は、大ボスのお題（大ボスが倒れるまで）をふくむ
- fps は自動プレイヤーでは測れない（画面がないため）。?tune で開いたゲームの右下と、調整パネルの「前回のバトル」で見る
