# 「消えたタオルと白い記憶」テスト版 決定事項メモ

## 目的と体制

タオルソムリエのゲームをベースに、ゲームのテスト版（プロトタイプ）を自分でClaude Codeを使って作る。本格版はプロが作る。

- 仮タイトル: 消えたタオルと白い記憶 〜消えたレシピを探す旅〜
- ターゲット: 小学4年生から中学生が中心。大人も楽しめる入門ゲーム
- 期間と時間: 1ヶ月、1日60分ほど
- 元資料: 9/7 関係者共有まとめ、9/14 確認事項、タオルの学校_入門編_v53_カード一覧.xlsx、タオルの学校_入門編_v53.html
- 資料の優先: 9/7と9/14で食い違うところは9/14を優先する
- 役割分担: 本人の試作はバトルとクイズ。世界観、キャラ、本番の音楽、背景はデザインチームが作る
- 世界観の方向: ストーリーの流れで少しメルヘンチックになる見込み。試作でも、見た目は仮のまま、手ざわりの方向はそれに合わせる（下記「見た目と音の方向」）
- このテスト版は「試作して捨てる」ものから「最終案まで作り続ける土台」に変わる。仮で済ませていたところは、順に本物の作りに置き換えていく。直しやすさ（どこを触れば何が変わるか）をゲーム性と同じ重さで扱う（10/21-1追加）
  - 直す場所は3か所に分ける: ことばのデータ（data/words.js）、ステージの数値（data/stages.js）、画面の言葉（data/texts.js）（10/21-1追加）

## 土台

入門編（v53）のコードは土台にせず、新規に作る。学校という設定は使わず、ゲームの中身もわくわくするものに作り直すため。

- v53から使うのは、カードとクイズの知識データだけ
- 「1年生」「卒業」など学校の呼び方は外し、9/14資料の世界名に付け替える（原材料の世界・製造工程の世界・タオル進化の世界）
- 3つの世界は、世界ごとに40枚、合計120枚のカード

## データ

語句は、いったんv53の120語を使う。あとで入れ替える可能性があるので、1か所のデータにまとめ、書き換えやすくする。

- 1語ごとの欄: 語句、クイズ（2択または3択）、一言メモ、硬さ、役割（ザコ／中ボス／大ボス）
- 並べ替え問題（製造工程の世界に多い）は、順序そのものを選択肢にして3択化する（例: ABC／ACB／BAC）
- 大ボスはv53の各ステージの「boss」を初期値にする。中ボスはいったん仮置き。最終的に本人が各ステージの中ボス・大ボスを決める。入れ替えは欄の書き換えだけで済むようにする
- ステージ1の大ボスは「天然の撚り」、中ボスは「ルーメン」「繊維長」。他のステージの中ボス・大ボスは仮置きのままでよい（10/3追加）
- 語句ごとに「出方」の欄（pattern）をwords.jsに持たせる。型は「ふつう／端にかくれる／横切る／雑魚のうしろ／地上のかげ」の5つ。ステージごとに意地の悪い語句を1〜2つ置く。ステージ1は仮に、コットンボール＝端にかくれる、リンター＝雑魚のうしろ。あとから欄の書き換えで調整できるようにする（10/3追加）

## 構成と進行

- 3世界×4ステージ＝12ステージ。ステージ名は9/14資料の表を使う
- 1ステージ＝バトル2分 → クイズ3分 → カード取得 → 10枚でレシピ完成。全体で約60分
- 12ステージで12のレシピがそろい、タオルをもう一度作る世界が復活する
- 7割正解で次のステージへ進める。世界の移動は40枚すべてが必要（テスト版でも同一）
- 取り逃がしたカードは、図鑑からクイズだけ受け直して埋める。バトルのやり直しは不要
- 世界の境界で止まったときは「あと◯枚で次の世界へ。図鑑から集めよう」の案内を出し、図鑑の該当ステージに飛べるようにする
- ステージ名は9/14資料のとおり。1 綿花のめざめ畑、2 世界のコットン街道、3 糸づくりの坂道、4 特別な繊維の森、5 タオルの道しるべ、6 糸が生まれる道、7 パイル織りの広間、8 仕上げチェックの門、9 タオルのかたち広場、10 生地のひみつ通り、11 かざりと機能のアトリエ、12 タオルマスターへの道。レシピ名は1 綿花のひみつ、2 超コットン、3 糸つむぎ。4以降は未定なので（仮）のまま（10/3追加）
- 7割クリアは「そのステージで集めたカードの合計が7枚以上」（10/3追加）
- ステージごとにベストスコアを記録し、3つの印をつける。「10語すべて回収」「やられなかった（体力ゼロにならなかった）」「被弾ゼロ」。印はステージ一覧に表示する。次のステージに進む条件ではない（10/3追加）
- ステージの難しさは stages.js の「難易度」の数値（1〜12）から自動で決まる。難易度から決まるもの: 敵の弾の量、敵の速さ、硬さ、意地の悪い語句の数、中ボス・大ボスの文字耐久。目安は世界1が意地の悪い語句1〜2で弾少なめ（今の手ざわり）、世界2が3〜4で弾が増える、世界3が5以上で横切る・端にかくれるが多く先回りが必要。難易度から各数値への線は調整パネルで動かせるようにし、ステージごとに個別の値で手上書きできる欄も stages.js に用意する（10/4追加）
- 印の「やられなかった」は「1機も失わなかった」に読み替える（10/3-3追加）

## バトル

1945のイメージ（骨組みは縦スクロールのシューティング）。敵が語句の文字で、倒すと語句を吸い込む。バトルは語句にふれる場で、定義はクイズで学ぶ。

- 機器と操作: スマホ縦画面、指一本のドラッグで自機を動かす。弾は自動
- 自機: A君（乗り物の形はデザインチーム待ち。試作では仮の形）
- ふわり: 最初から自機の横にいる前提。集めたカードの総数で強くなり、色と数字でそれを表す（10枚ごとに弾が増えるなど3〜4段階）。合流の演出はデザインチームが後から乗せる
- 敵: 語句の文字。敵は弾を撃ってくる（弾は文字でなくてよい）
- 10語の内訳: ザコ6〜7語、中ボス2〜3語、大ボス1語（最後に登場）。硬さの初期値はザコ1発、中ボス3発、大ボス6〜8発。触って調整する
- 体力制。語句を吸い込むと少し回復。ゼロになったら、吸い込み済みの語句は保持したまま、残りの語句だけで再開する（最初からのやり直しはしない）
- 画面の下へ抜けた語句は、しばらくすると再び出てくる。10語そろうまでバトルは続く
- 読むのはバトル中ではなく、吸い込んだ瞬間。吸い込んだ語句を画面中央に大きく表示する（読み仮名つき、0.5〜0.8秒）。敵の動きは1945よりゆっくり、文字は24px以上
- 2分で10語＋大ボスが収まる速さを、敵の出る間隔の初期値にする
- 空中と地上の2層と雑魚は残す。ただし語句の敵が主役。語句にはふりがな（漢字の上に小さく）と光る縁取り、文字は雑魚より大きく。雑魚は小さく薄い色にして数を減らし、語句の近くには出さない（10/3追加）
- 語句は1バトルで2回出る。1回目は倒せるが吸い込まず、ふわりが反応して光って消えるだけ。2回目で倒して吸い込む。下へ抜けた分はさらに戻ってくる（10/3追加）
- 吸い込む瞬間は0.3秒ほど画面全体がゆっくりになり、語句とふりがなを中央に大きく1.0秒表示。その間は弾が当たらない。表示中に語句を読み上げる（iPhoneの読み上げ機能で仮に）（10/3追加）
- 語句を吸い込んだ瞬間、光が広がって画面上の雑魚と敵弾が全部消える（10/3追加）
- 画面の端に「集めたことば」の帯を置き、吸い込んだ語句が並んでいく（10/3追加）
- 語句を吸い込むごとにバトルの中で強くなる（1945型）。3語ごとに1段階、弾1本→2本→3本→3本で連射が速い。毎バトルゼロから。カード総数は数字の表示だけに使い、強さには関係させない（上の「ふわり」の行の、カード総数で強くなる案から変更）（10/3追加）
- 得点を入れる。語句は雑魚の10倍の点。語句を連続で倒すとコンボ倍率。ステージの終わりに点数とランク（タオル見習い〜タオル博士の4段階くらい、仮）を出す（10/3追加）
- 語句の出る順番と軌道はステージごとに固定する。ランダムはやめる。1945のように、覚えて先回りできる形にする（10/3追加）
- バトルは「2周＋大ボス」の構成にする。1周目は10語が決まった順番と出方で出て、倒すと光って消えるだけ（ふわりの記憶が薄く吸い込めない）。2周目は同じ順番・同じ出方で来て、今度は吸い込める。2周したら、回収できていない語句があっても大ボス戦へ進む。大ボスは2周目のあと1回。目安は1周目50秒、2周目50秒、大ボス20秒。1周目は雑魚を少なめにして速く流す（10/3追加）
- 「下へ抜けた語句は戻ってくる」のルールは外す（2周の構成に置き換え）（10/3追加）
- 中ボスと大ボスは「1文字ずつ壊す」作りにする。語句の文字がそれぞれ部品で、弾を当てた文字から順に砕け、砕けるたびにその文字の読みが鳴る。全部砕けると語句まるごとを吸い込む。硬さ（hp）は文字1つあたりの耐久に読み替える（10/3追加）
- 「ぜんぶ消し」ボムを入れる。コンボを溜めるとゲージがたまり、満タンで1回使える。使うと画面の雑魚と敵弾を全部消し、出ている語句を全部「反応」させる（1周目扱いの光）。使い方は画面のふわりマークをタップ。ゲージの溜まる速さは調整パネルに入れる（10/3追加）
- 吸い込んだ瞬間の語句の表示時間は1.0秒→1.5秒（10/4追加）
- 1周目の始まりにふわりの一言「ことばを見つけよう（まだ吸い込めないよ）」、2周目の始まりに「思い出した！今度は吸い込める！」を出す（10/4追加）
- 大ボスの1文字あたりの耐久を今の2倍にする（ステージ1でも）（10/4追加）
- 中ボス・大ボスの硬さは「語句全体の硬さ」を役割で決め、文字数で割って1文字あたりの耐久にする。文字あたりの耐久には上限と下限をつける（1文字の語句が1発で壊れないように）。これで文字数が違っても合計の硬さはそろう（10/4追加）
- かっこと、かっこの中の別名は、壊す部品と読み上げから外す（10/4追加）
- 1〜2文字の語句には「端にかくれる」「横切る」の出方を付けない。短い語句は文字を大きめに表示する（10/4追加）
- 2周目の中ボス戦（2回）と大ボス戦（1回）を「お題バトル」にする。ふわりがお題を出し（その語句のクイズ問題をそのまま使う）、画面に3つの語句が並ぶ。本物1つと、同じステージの別の正しい語句2つ。本物を撃つと1文字ずつ砕けて吸い込める。ダミーを撃つと弾がはね返り「ちがうよ」の表示と少しの減点。最初から本物を当てたら「ひらめき」ボーナス。1周目の中ボスは今までどおり見るだけ。ザコ7語の扱いは変えない（10/5追加）
- お題バトルは調整パネルでオン・オフできるスイッチつきで作る。オフにすると今の中ボス・大ボス戦に戻る。ダメなら戻すことを前提にする（10/5追加）
- お題バトルの細かい決まり: 間は台本を止める／中ボスの制限時間20秒、時間切れは取り逃がし／ダミーはステージごとに固定、ならびは毎回入れかえ／3つとも同じように撃つ（撃ち方で本物がわからないように）／ダミーに当てたら−300点、コンボは切らない、ひらめき+2000点（いずれも調整パネルで動かせる）／中ボス・大ボスの問題はバトルのあとのクイズにもそのまま出す（10/5追加）

## 進め方

まず世界1の最初のステージ（綿花のめざめ畑）を、バトル、クイズ、カード、レシピ完成まで通して遊べる形にする。触って確かめてから、他のステージと世界に広げる。

- 公開はGitHub Pages。スマホはURLで開いて試す。GitHubの準備はClaude Codeの最初の作業に含める
- 作る順番は、ゲーム（バトル）が先、シナリオはあと
- バトルの細かい調整（弾の量、吸い込みの表示時間、硬さ）は、試作を触って決める
- チャットとClaude Codeを行き来して進める。プロジェクトを作って管理する
- 版は日付のフォルダで管理する。まず、今公開されている版（今回の手直しの前）を、その版の最後のcommitの日付で versions/YYYYMMDD/ に丸ごとコピーして公開する。あわせて同じ名前のタグをつける（10/7-1追加）
- 今回の手直しが終わったら、できあがった版を versions/20261007/ にコピーして公開し、タグ v20261007 をつける。以後、作業した日ごとに同じ手順で versions/日付/ を増やす。親のURL（https://nttakahiro-ui.github.io/kieta-towel/ ）は常に最新版（10/7-1追加）
- 進捗メモの先頭に版の一覧（日付、URL、その版の要点）を置き、版を増やすたびに更新する（10/7-1追加）
- チュートリアルを「見た」の記録は、版（versions/のフォルダ）ごとに分けて保存する。別の版を開いたときはチュートリアルが出るようにする（10/7-1追加）
- 作る前に、今公開されている版を versions/20261007/ に保存してタグ v20261007（まだなら）。今回の作業が終わったら versions/20261021/ にコピーしてタグ v20261021。作業は3回に分けて、回ごとに公開して確かめる（10/21-1追加）
- 公開済みのタグは動かさない。同じ日に複数回公開したときは、タグに b、c と足す（例: v20261025b）。進捗メモの版の一覧もそれに合わせる（10/25-4追加）
